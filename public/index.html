Tentang Modul Ini

Pada modul pertama ini, kita mempelajari bagaimana sistem e-learning mengamankan video menggunakan teknik custom masking player (Plyr.js) dan dynamic floating watermarking tanpa membebani storage dan bandwidth server utama.

Poin Proteksi yang Sedang Aktif:

  • Zero Direct YouTube Link: UI bawaan YouTube (judul, tombol bagikan, avatar) ditutupi oleh Shield Overlay.
  • Custom Controls (Plyr): Pengaturan kecepatan, seekbar, volume, dan fullscreen dikelola oleh player kustom.
  • Dynamic Watermark: Identitas user (baim@elearning.test) berpindah-pindah posisi setiap 10 detik.
  • Anti-Inspect & Klik Kanan: Mencegah akses mudah ke URL embed lewat menu konteks.

1. YouTube Unlisted

Video tidak muncul di pencarian publik YouTube, hanya dapat diakses melalui player ini.

2. Plyr UI Masking

Seluruh antarmuka kontrol diganti menggunakan Plyr.js bernuansa gelap dan premium.

3. Transparent Click Shield

Mencegah klik pada logo YouTube atau tombol "Watch on YouTube".

4. Dynamic Watermark

Identitas user ditempel di video untuk mencegah pembajakan via rekaman layar.
